# Catálogo de sagas de películas

Este repositorio contiene un pequeño catálogo de sagas cinematográficas: El Señor de los Anillos, Harry Potter y Star Wars.
Cada saga tiene su carpeta con un archivo de prólogo (xxx_prologo.txt) y otro con el listado de películas (xxx_capitulos.txt).
Sirve como base de contenidos para una futura página web y como práctica de Git y GitHub.
